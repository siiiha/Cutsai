# 작업실 React 화면

PDF 「제목 없음」 기준 20페이지를 원본 순서에 맞춰 React 화면으로 구성했다. src/screens에 페이지별 JSX가 있고, 공통 스타일은 src/styles.css에 있다.

## 실행

1. Node.js가 설치된 환경에서 이 폴더를 연다.
2. npm install
3. npm run dev
4. 터미널에 표시된 주소를 열고, 특정 화면은 주소 끝에 ?page=1부터 ?page=20까지 붙여 확인한다.

npm run build로 dist에 배포용 파일을 생성할 수 있다.

일부 버튼은 PDF의 화면 흐름을 확인할 수 있게 연결했다. 인증, 저장, 점검 및 업로드를 수행하는 서버 기능은 포함하지 않는다. 표현은 1440×900에서 확인하는 것을 기준으로 하며, 설치 글꼴과 PDF·브라우저의 렌더링 차이로 픽셀 단위 차이가 생길 수 있다.
