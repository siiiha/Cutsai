# AI 사용 작업 기록

## 2026-11-25 ~ 2026-11-26: 이메일 인증과 비밀번호 재설정

- 목적: 회원가입과 비밀번호 재설정에서 공통으로 사용할 이메일 인증을 구현하고 화면과 연결한다.
- AI 제안·작성: 인증번호 발송·검증·재발송, 발송 제한과 인증 목적별 상태 관리, 지메일 발송 설정, 회원가입 인증 확인, 비밀번호 재설정과 로그인 유지 토큰 폐기, 공통 인증 입력 및 화면 요청 연결을 구현했다. 로그인·토큰 재발급과 비밀번호 재설정의 동시 처리 순서를 조정했다.
- 개발자 검토·수정: 사용자가 각 단계의 변경 대상과 내용을 확인하고 진행을 승인했다. 코드에 대한 별도 개발자 검토·수정 여부는 확인되지 않았다.
- 검증: 이메일 인증번호의 실제 지메일 발송·수신, 정상 검증, 만료, 5회 오입력 제한, 재발송 후 이전 번호 거부, 인증 목적 구분을 사용자가 확인했다. 인증 서비스와 회원가입 테스트, API 요청 검증과 메일 내용 테스트를 실행했으며, 이후 변경에 대해 백엔드 컴파일과 프런트엔드 빌드를 확인했다.
- 남은 확인: 회원가입과 비밀번호 재설정의 화면 전체 흐름, 데이터베이스 트랜잭션과 동시 로그인·토큰 재발급 동작은 실제 환경에서 추가 검증이 필요하다.

## 2026-11-27: 서비스 인터페이스와 구현체 분리

- 목적: 모든 Spring 서비스가 도메인 서비스 인터페이스와 `Impl` 구현체를 사용하도록 구조를 통일한다.
- AI 제안·작성: `AuthService`, `LoginService`, `MemberService`의 계약과 구현을 분리하고, 구현체를 직접 생성하는 테스트 참조를 변경했다.
- 개발자 검토·수정: 사용자가 기존 세 서비스 구조를 확인한 뒤 남은 서비스 분리와 생성자 참조 수정을 함께 진행하도록 승인했다.
- 검증: `git diff --check`를 실행할 예정이며, 테스트 실행은 사용자가 나중으로 미뤄 이번 단계에서는 하지 않는다.
- 남은 확인: 테스트를 실행해 서비스 주입과 직접 생성 흐름이 정상인지 확인한다.
